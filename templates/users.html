How roles work

👑 Admin

Full access — jobs, candidates, screening, interviews, plus this user management page and the Django admin console.

🎯 Recruiter

Runs the entire hiring workflow. Cannot manage users or access the Django admin console.

🛡️ Safety guards

You can't demote or disable yourself, and role changes require confirmation — so the workspace always keeps at least one Admin.
